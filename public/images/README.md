# Images for Elad Kids Games

| Asset           | Folder                 | File          |
|-----------------|------------------------|---------------|
| Homepage hero   | `home/`                | `homepage.png`|

Drop game images into the folder they belong to.

| Section   | Game              | Folder                         | Files needed                          |
|-----------|-------------------|--------------------------------|--------------------------------------|
| Hebrew    | Tap the Letter    | `hebrew/tap-the-letter/`       | (future use)                         |
| Maths     | Count the Objects | `maths/count-the-objects/`     | `apple.png`                          |
| English   | Match the Word    | `english/match-the-word/`      | `cat.png`, `dog.png`, `sun.png`, `star.png` |

**Adding a new game?** Create a folder: `{section}/{game-slug}/` and put the game's images there.
